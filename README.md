# 힘 단위 변환기

Tkinter 기반의 데스크톱 GUI 프로그램입니다. 힘 값을 kN, N, kgf 사이에서 변환하고 변환 결과를 기록합니다.

## 기능

- 입력한 힘을 `kN`, `N`, `kgf` 중 선택한 단위로 변환합니다.
- 숫자 키패드 또는 키보드로 값을 입력하고, Enter 키로 변환할 수 있습니다.
- 단위 바꾸기 버튼으로 입력 단위와 출력 단위를 맞바꿀 수 있습니다.
- 변환 기록은 최신 결과부터 표시됩니다. 기록을 더블클릭하면 해당 값과 단위 선택을 다시 불러오며, 기록 지우기 버튼으로 기록 전체를 삭제할 수 있습니다.
- 초기화 버튼은 입력값과 단위를 기본값(`kN`에서 `N`)으로 되돌립니다. 종료 버튼은 프로그램을 닫습니다.

변환 기준은 `1 kN = 1000 N`, `1 N = 1 N`, `1 kgf = 9.80665 N`입니다. kgf 환산은 표준중력가속도 기준입니다.

## 필요한 환경

- Python 3
- Python 배포판에서 사용할 수 있는 `tkinter` 및 데스크톱 GUI 실행 환경
- 별도의 서드파티 Python 패키지는 코드에서 사용하지 않습니다.

## 실행 방법

터미널에서 `force_converter.py`가 있는 폴더로 이동한 뒤 실행합니다.

```bash
python3 force_converter.py
```

## 입력 예시

단위 버튼으로 입력 단위와 출력 단위를 선택한 뒤 값을 입력하고 **변환**을 누릅니다. 아래 예시에서 입력 단위는 `kN`, 출력 단위는 `N`입니다.

| 입력값 | 결과 |
| --- | --- |
| `2.5` | `= 2500 N` |
| `-1` | `= -1000 N` |
| `0.001` | `= 1 N` |

소수와 음수 입력이 가능합니다. 키보드로 직접 입력하거나 화면의 숫자 키패드를 사용할 수 있습니다.

## 오류 입력 예시

| 입력 | 표시되는 안내 |
| --- | --- |
| 빈 값 | `값을 입력해주세요.` |
| `abc` | `'abc' 은(는) 숫자가 아닙니다. 예: 12.5` |

오류는 디스플레이에 표시됩니다. 입력을 수정하거나 지운 뒤 다시 변환할 수 있습니다.
